💾 Backup do sistema

Gere um backup completo dos dados do sistema. O backup será criado e enviado automaticamente para o Google Drive configurado no sistema.

Como funciona:
1. O sistema gera o backup do banco de dados.
2. O arquivo é compactado.
3. O backup é enviado para o Google Drive.
4. O arquivo temporário local é removido após o envio.
⚠️ Importante: Após alterar sua senha, sua sessão será encerrada e será necessário fazer login novamente.
